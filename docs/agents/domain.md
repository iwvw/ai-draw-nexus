# Domain Docs

This repo uses a single-context documentation layout.

## Before Exploring

Read these files first:

- `CONTEXT.md`
- ADRs under `docs/adr/` that touch the area being changed
- The active PRD under `docs/prd/`
- The current handoff under `docs/process/agent-handoff.md`

## Vocabulary Discipline

Use the terms from `CONTEXT.md` in issue titles, implementation notes, route names, tests, and handoff summaries. If a new concept is needed, add it to `CONTEXT.md` before spreading the term across code or docs.

## ADR Conflicts

If a proposed change contradicts an ADR, call it out explicitly and either update the ADR or add a new one.
